Initial available data should be in initial_data_files folder.
Generated data is being saved in generated_data_files folder. 

TRY NOT TO MODIFY THE GENERATED DATA FILES UNLESS YOU KNOW WHAT YOURE DOING. THE CODE IS FILE FORMAT SENSITIVE

Programm running sequence:

1. data_fit.py (if no .ce file is generated)

2. predict_plot_analyze.py (To see the free energy dependence from GGI and/or AAC (Modify the code correspondingly))

3.heatmaps.py (To get the free energy plot from GGI and AAC obtained from cluster expansion predictions)

4. thermo_integration.py (To do canonical Monte Carlo simulation and save the generated energy over GGI 
                          or AAC data (Modify the code correspondingly))

5. temperature_integration.py (To do canonical Monte Carlo simulation and save the generated energy over GGI 
                               or AAC data (Modify the code correspondingly))


6. canonical_data_analyzer.py (To analyze data generated by thermo_integration.py and temperature_integration.py scripts)

7. SGC.py for simulation of Semi-grand-canonical ensemble 

8. VCSGC.py for for constrained ensemble simulation.
